# Overview Project

WEBSITE UNTUK MEDIA SPEAK-UP INTERAKTIF DENGAN FITUR
PRIVASI TERJAGA SEBAGAI RUANG AMAN PENGADUAN KELUHAN REMAJA DI IMPLEMENTASIKAN UNTUK SEKOLAH SMP DI JAKARTA.


Latar belakang masalah : 
Remaja menghadapi berbagai keluhan dalam
kehidupan sehari-hari, terutama di lingkungan sekolah. Masalah seperti bullying,
tekanan akademik, konflik pertemanan, hingga masalah emosi sering kali membuat
mereka merasa tertekan dan kesulitan mencari wadah untuk berbagi.

Namun, rendahnya angka pelaporan masih menjadi kendala utama dalam penanganan
masalah ini. banyak remaja memilih
Diam karena takut akan stigma sosial atau kurangnya kepercayaan pada efektivitas
sistem pengaduan yang ada. Tanpa mekanisme pengaduan yang aman, rahasia, dan
interaktif, masalah-masalah tersebut akan terus terabaikan dan memperlemah peran
sekolah sebagai lingkungan pendukung.

Solution : 

Diperlukan inovasi digital yang dapat menjembatani kesenjangan ini,
yaitu website platform pengaduan yang menjamin keluwesan anonimitas, interaktivitas, dan
privasi tinggi, sehingga remaja berani speak up tanpa rasa takut.

Whispr hadir sebagai web media speak up interaktif yang dirancang khusus untuk
menampung keluhan remaja terkait masalah mereka, dengan fitur privasi terjaga sebagai
ruang aman pengaduan. Platform ini memungkinkan pengguna berbagi cerita,
mendapatkan respons, dan saran solusi, sehingga menciptakan ekosistem dukungan
yang inklusif tanpa risiko identitas terungkap.



# Role 
- User : students can access without login (students)
- Admin : for manage dashboard (school counselor)

# USER FLOW PUBLIC


- Complaint (keluhan) → anonim total, tanpa email, sekali kirim (admin baca & proses, user tidak cek balasan)
- Consultation (konsultasi) → anonim, tapi email diminta hanya untuk kirim kode/token unik → nanti user pakai token itu buat cek balasan admin (semacam sistem tiket tanpa akun/password)

1. Flow (Complaint Message for Anonymous)

- Landing page
- Input complain message text (required) and add image (optional)
- Select option category
- submit

Complaint (keluhan) → anonim total, tanpa email, sekali kirim (admin baca & proses, user tidak cek balasan)

2. Flow (Consultation Message)

- Landing page
- Input complain message (required) and add image (optional)
- Select option category
- Input email
- Submit

Consultation (konsultasi) → anonim, tapi email diminta hanya untuk kirim kode/token unik → nanti user pakai token itu buat cek balasan admin (semacam sistem tiket tanpa akun/password)


3. User perlu login atau tidak

- untuk Complaint Message (Anonymous) tidak perlu login 
- untuk Consultation mendapatkan kode/token unik di kirim ke email nya untuk ce balasan nanti.
